## Citation Format

All sources above follow this format:
- **Title**
- Publisher/Source
- URL (primary and secondary where applicable)
- Year
- Topic/Description

---

## Usage Guidelines

When citing in documents:
1. Use numbered citations: [1], [2], etc.
2. Link directly to source URL
3. Include year for context
4. For papers, include arXiv number or DOI

Example:
```
According to Natural Hoare Logic research [1], formal specifications can be
extracted from natural language with 75-85% accuracy using compositional
semantic parsing.

[1] Natural Hoare Logic (arXiv:2103.05779, 2021)
    https://arxiv.org/abs/2103.05779
```
